# Бот "Во сколько вставать"

Пошаговая инструкция для тех, кто никогда не делал ботов.

## Шаг 1. Получить токен бота

1. Откройте в Telegram чат с **@BotFather**.
2. Отправьте команду `/newbot`.
3. Придумайте имя бота (любое, для отображения) и username (должен заканчиваться на `bot`, например `MyWakeUpBot`).
4. BotFather пришлёт токен вида `123456789:AAExampleTokenHere`. Скопируйте его — он понадобится дальше.

## Шаг 2. Настроить бота под себя

Откройте файл `bot.py` и в блоке `CONFIG` (в начале файла) поправьте под свою реальную ситуацию:

- `PREP_MINUTES` — сколько минут уходит на сборы после пробуждения
- `TRAVEL_MINUTES` — сколько минут вся дорога от дома до работы
- `BUFFER_MINUTES` — запас на всякий случай
- `TRANSPORT` — например, "автобус №12", "метро", "пешком"
- `NEAREST_STOP` — название ближайшей остановки/станции

По умолчанию цифры взяты из вашего примера (подъём 12:30 → выход 14:00 → работа 15:00), но их стоит перепроверить под реальный маршрут.

## Шаг 3. Проверить бота на своём компьютере (необязательно, но полезно)

Если у вас установлен Python 3.11+:

```bash
pip install -r requirements.txt
export BOT_TOKEN="ваш_токен_из_шага_1"     # на Windows: set BOT_TOKEN=ваш_токен
python bot.py
```

Дальше откройте своего бота в Telegram и напишите ему: «мне надо на работу к 15:00».

Пока этот процесс запущен на вашем компьютере — бот отвечает. Как только вы закроете терминал или выключите компьютер — бот перестанет отвечать. Поэтому для круглосуточной работы нужен облачный хостинг (шаг 4).

## Шаг 4. Разместить бота в облаке, чтобы он работал 24/7

Самый простой бесплатный вариант — **Railway.app**:

1. Зарегистрируйтесь на https://railway.app (можно через GitHub-аккаунт).
2. Создайте новый проект → «Deploy from GitHub repo» (нужно будет загрузить туда эти файлы: `bot.py` и `requirements.txt` — самый простой способ это сделать через сайт github.com: создать новый репозиторий и загрузить файлы через кнопку "Add file → Upload files").
3. В настройках проекта на Railway откройте вкладку **Variables** и добавьте переменную:
   - `BOT_TOKEN` = ваш токен из шага 1
4. В настройках запуска (Start Command) укажите: `python bot.py`
5. Railway сам установит зависимости из `requirements.txt` и запустит бота. После этого бот будет работать постоянно.

Альтернативы Railway, если он не подойдёт: **Render.com** (Background Worker) или **PythonAnywhere**.

## Как бот считает время

Пример: вы пишете «мне надо на работу к 15:00»

```
15:00  — время, к которому нужно быть на месте (из вашего сообщения)
минус TRAVEL_MINUTES + BUFFER_MINUTES  → время выхода из дома
минус PREP_MINUTES                     → время подъёма
```

Если написать время, которое уже прошло сегодня (например, сейчас 20:00, а вы пишете «к 9:00»), бот посчитает это на завтра.
